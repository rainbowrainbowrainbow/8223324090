# Entity: Design Asset

## Meaning

A Design Asset is an uploaded/managed visual asset for design boards and catalog presentation.

## Fields / Properties

Source evidence: `routes/designs.js`.

- id
- filename/path/url
- tags
- collection
- calendar/date metadata
- download/send status

## Related Entities

- Can belong to collection.
- Can be used in catalog pages/items.
- Can be sent to Telegram where supported.

## Where It Appears

- Designs page.
- Art Director/catalog workflows.

## Assistant Interpretation

On Designs, distinguish uploaded design assets from product/catalog data.
