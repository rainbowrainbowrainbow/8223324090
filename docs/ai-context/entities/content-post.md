# Entity: Content Post

## Meaning

A Content Post is a social/content matrix item managed by Content and Art Director workflows.

## Fields / Properties

Source evidence: `routes/content.js`, content migrations.

- id
- platform/account
- title/content
- status
- schedule date/time
- template
- approval/regeneration metadata

## Related Entities

- Uses templates/social accounts.
- May be approved/rejected by product/creative roles.

## Where It Appears

- Content page.
- Art Director page.

## Assistant Interpretation

On Content/Art, interpret status questions around draft/approval/scheduled/published/failed workflow if visible.
