# Entity: Task

## Meaning

A Task is the CRM operational work item. Tasks can be personal, delegated, source-linked, smart-scheduled, special-control, or generated by workflows.

## Fields / Properties

Source evidence: `services/dashboardAssistant.js`, `services/taskPolicy.js`, `routes/tasks.js`.

- `id`
- `title`
- `status`
- `priority`
- `category`
- `owner_user_id`
- `assigned_to` / owner labels
- `created_by_user_id`
- `deadline` / `date`
- `source_type`
- `source_id`
- `created_at`
- smart scheduling/control metadata where migrations add it.

## Related Entities

- Task may be linked to Booking, Lead, Customer, Conversation, Graduation flow, Contractor, or internal source.
- Task has owner and creator.
- Task may have observers/visibility policy.

## Where It Appears

- Tasks page.
- Dashboard widgets/work queue.
- Chat-to-task flow.
- Graduation missing-roster automation.
- Contractor tasks.

## Assistant Interpretation

When answering about tasks, use current user's role, owner, created-by, due date, priority, source, and status. Do not expose hidden tasks outside visibility policy.
