Каталоги матеріалів

Ці групи допомагають швидко зібрати матеріал для реклами, презентації або клієнтського каталогу без пошуку по всій CRM.

Квести та пригоди

Темні сцени, маршрут, світло і предметний фокус. Підходить для афіш, stories і teaser-постів.

Шоу та програми

Яскрава сцена з вільним центром для заголовка. Добре працює для анонсів і банерів.

Майстер-класи

Тепле світло, багато фактур і рукодільна тема. Основа для дитячих та творчих пропозицій.

Фото-зони та приватні події

Чистий простір у центрі, м'які акценти та готова зона для назви пакета або дати.

Правила використання бренду Event Genix

Гайд описує загальний CRM-бренд. Матеріали ДАР, Майстерні долі та Парку використовуються тільки як приклади окремих клієнтських стилів.

Назва

Event Genix пишемо з пробілом і двома великими літерами. У продукті не скорочуємо до EG.

Логотип

Основний знак для CRM-гайду — кольоровий мозаїчний круг. Золотий gear mark лишається службовим знаком у sidebar і технічних місцях.

Масштаб

Для екрана тримаємо знак не менше 64 px у презентаційних блоках і не розтягуємо його по одній осі.

Мова

Продуктові та рекламні матеріали готуємо українською. Код, id і технічні назви лишаються англійською.

Композиція

Правильно

Один сильний заголовок, реальне зображення, чиста зона для тексту, один заклик до дії.

Не треба

Багато емодзі, дрібний текст поверх деталей, випадкові кольори, змішування логотипів різних брендів.

Перед публікацією

Перевірити назву бренду, контраст, відступи навколо логотипа, читабельність на телефоні та відповідність матеріалу конкретній компанії.

Brand Book Event Genix

Event Genix звучить як робочий інструмент для команди: ясно, спокійно, без зайвої магії в тексті. Візуально бренд може бути яскравим, але інтерфейс має лишатися зручним для щоденної роботи.

Призначення

CRM збирає операційні матеріали, бронювання, каталоги, задачі та рекламні assets в одному місці для команд подій і сервісних бізнесів.

Голос

Тексти короткі, конкретні й корисні. Пояснюємо результат дії, не продаємо через тиск і не обіцяємо те, що система не підтверджує даними.

Візуальний принцип

Одна сильна фотографія або ілюстрація, чиста зона для тексту, мозаїчна палітра як акцент і зрозумілий CTA.

Для клієнтських брендів

ДАР, Майстерня долі й Парк мають окремий голос і палітри. У CRM вони мають бути позначені як матеріали конкретної компанії.

Приклади голосу

Event Genix

Готовий макет для афіші збережено в Design Board. Перевірте текст, дату й компанію перед публікацією.

Дитячий Активний Розвиток

Теплий освітній тон: прості формулювання, багато повітря, біле тло, зелений як основний акцент.

Майстерня долі

Спокійний рефлексивний тон: без гарантій результату, без тиску, з м'яким запрошенням до діалогу.

Кольори Event Genix

Палітра взята з наявного мозаїчного знака й адаптована для CRM: синій для довіри, зелений для готовності, рожевий і помаранчевий для рекламних акцентів.

Типографіка

Nunito

Event Genix керує матеріалами без хаосу

Nunito використовується для великих презентаційних заголовків, коли сторінка має звучати дружніше.

Inter

Design Board показує статус файлів чесно

Inter лишається основним шрифтом CRM для таблиць, форм, меню, списків і робочих станів.

UI правила

Cards

Для робочих карток тримаємо радіус 12-14 px, чіткий border і без вкладених декоративних карток.

Spacing

Базовий крок 8 px. Між секціями 24 px, між картками 12 px. У рекламних прев'ю залишаємо більше повітря навколо логотипа.

States

Недоступний файл показуємо як unavailable state. Не малюємо preview, якщо байтів немає.

Шаблони дизайнів

Шаблони тут описують формат і композицію. У наступній задачі їх можна перетворити на реальні downloadable demo-файли.

Stories 1080×1920

Каталог A4

Презентація програми

Широкий cover, короткий опис, 2-4 ключові умови й фінальний слайд з контактною дією.
