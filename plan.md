# План: Адаптивний layout коли права панель закрита

## Проблема
Коли booking panel закрита, основний контент не розтягується на повну ширину.
Віджети дашборду маленькі, багато порожнього простору справа.

## Що змінити

### 1. CSS layout.css — `.main-content`
- Прибрати `max-width: 1800px` (обмежує розтягування)
- Контент має займати `calc(100% - sidebar)` завжди
- Плавний перехід при відкритті/закритті панелі

### 2. CSS layout.css — `.main-content.panel-open`
- Додати `margin-right: 340px` замість `padding-right: 360px`
- Так контент реально звужується, а не просто отримує паддінг

### 3. CSS dashboard.css — `.dashboard-grid`
- Зменшити мінімум колонки: `minmax(340px, 1fr)` → `minmax(300px, 1fr)` для кращого заповнення
- Додати breakpoint для >1400px — 4 колонки

### 4. Перевірити інші сторінки
- Таймлайн, задачі, клієнти — чи вони теж розтягуються правильно

## Файли
- `css/layout.css` — main-content
- `css/dashboard.css` — grid
