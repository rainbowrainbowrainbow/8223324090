# Omni: виправлення адаптивності, 17.09.2026

## Причина

Заголовок діалогу розподіляв ширину між ім’ям і всіма діями в одному flex-рядку. Ім’я могло стискатися до кількох пікселів та збільшувати висоту заголовка. Окремі правила на 768 і 1100 px суперечили одне одному; мобільний діалог примусово перекривав усю CRM. Фільтри, статистика та постійний банер забирали висоту списку.

## Рішення

- Єдиний набір локальних правил у `css/omni-workspace.css`; компонування залежить від доступної ширини Omni та діалогу.
- Ім’я й аватар мають власний рядок. Дії розміщені окремо, другорядні команди на вузькій області доступні через «Ще».
- Висота враховує фактичне положення робочої області та visual viewport. Список і повідомлення прокручуються незалежно; composer не стискається.
- Замість широкого банера — індикатор із деталями. Повернення з каналів явне. Статистика доступна в додаткових фільтрах.
- Повернення до списку зберігає позицію та фокус; чернетки використовують наявний механізм. Auth, API, business scope та підключення не змінені.

## Перевірено локально

- Node 22.23.1 / npm 10.9.8; 76 цільових unit-перевірок; parser-перевірка та CSS ownership.
- Реальні скрипти сторінки та кліки у Chrome, контрольовані API fixtures, перехоплення всіх записів. Жодної відправки справжнім клієнтам.
- 1440×900, 1366×768, 1180×700, 1024×600, 390×844, 320×640, 390×420; довге ім’я, меню дій, composer. На 1024×600 видно більше чотирьох повних рядків.
- Пошук, статус зі спамом, очищення, порожні результати, канал; канали → стан → назад; чернетки, прокрутка списку, повернення фокусу; світла/темна тема.
- Існуючий функціональний smoke: пагінація 105 розмов/повідомлень, ізоляція чернеток, захист від застарілих відповідей, призначення, вкладення, помилки закриття та каналів.
- Справжній browser zoom 100/125/150% на базових viewport 1366×768 і 1024×600: `chrome.tabs.setZoom` у тимчасовому Chromium-профілі; масштаб підтверджено `getZoom`, DPR і зміною viewport. Це не CSS scale або емуляція pinch.

Артефакти: `output/playwright/omni-completion/` — скриншоти, `layout-metrics.json`, `native-zoom.json`.

Запуск:

```powershell
npm exec --yes --package=playwright -c 'node tests/browser/omni-responsive-browser-smoke.js'
npm exec --yes --package=playwright -c 'node tests/browser/omni-completion.fixture.cjs'
$env:OMNI_NATIVE_ZOOM='1'
npm exec --yes --package=playwright -c 'node tests/browser/omni-completion.fixture.cjs'
Remove-Item Env:OMNI_NATIVE_ZOOM
```

Тестовий логін читається локально з узгодженого secrets-файлу, не записується в звіти. Native zoom потребує bundled Chromium Playwright.

## Межі доказів

- Фізична екранна клавіатура телефона не перевірена: перевірено короткий viewport і visual viewport handling.
- Desktop collapse у поточному shared sidebar вимкнений самим renderer; перевірені розгорнуте desktop-меню та реальне мобільне відкриття/закриття.
- Інтеграційні доставки провайдерів не є частиною виправлення верстки. Відправлення у browser fixture локальні.
- Production SHA, CI та результат live QA фіксуються після релізу; локальні fixtures не є доказом стану production.
