# Historical Documentation Archive

This folder keeps historical Event Genix notes that are useful for context but
are not current operating authority.

Current source-of-truth documents:

- `AGENTS.md` at the repository root for agent working rules.
- `README.md` at the repository root for setup, verification, versioning, and deploy boundaries.
- `DB_MIGRATION_GOVERNANCE.md` at the repository root for database migration rules.
- `CHANGELOG.md` at the repository root for release history.

Archived files in this folder may contain stale runtime, branch, deploy,
version, test-count, or workflow instructions. Treat them as historical evidence
only.
